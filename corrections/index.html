Policy

Regulatory information changes, and we will sometimes get something wrong. When a substantive error is found - a wrong date, fine, price, or requirement - we correct it and note the correction on the affected page rather than silently rewriting history.

Correction format: Correction - [date]: An earlier version of this guide stated X. Current DSNY guidance says Y.

Spot an error? Tell us. Please include the page and, if you have it, the official source.
